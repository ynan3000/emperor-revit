Install in two minutes

Works with Autodesk Revit and pyRevit.

  1. Install pyRevit
    Get it from the pyRevit GitHub page if you do not have it yet.
  2. Download Emperor
    Emperor_v1.6.2.zip from GitHub releases.
  3. Extract
    Into your pyRevit extensions folder, so you get Emperor.extension.
  4. Start Revit
    Or pyRevit > Reload. The Emperor tab appears.

FAQ

 

Is Emperor for Revit free?

Yes. It is free and open source under the MIT License – use it at work, change it and share it.

Which Revit versions are supported?

It is tested on Revit 2025 with pyRevit 7. The DWG option that binds images as OLE needs Revit 2025 or newer.

Do I need AutoCAD to put images inside DWG files?

No. The Emperor Exporter binds the images into the DWG itself, without AutoCAD.

Is it only for HVAC engineers?

No. The HVAC panel is for mechanical engineers, but View Manager, Link Manager, Room & Space Manager, Excel to Drafting, the Exporter and the toggles help every discipline.

Where do I report a bug or ask for a feature?

Open an issue on GitHub or message me on LinkedIn.
