Welcome to Emperor

New here? This page takes about five minutes and gets you from install to your first result.

Your first 5 minutes

  1. Install - extract the ZIP into your pyRevit extensions folder and start Revit (details in Install).
  2. Find the tab - a new red Emperor tab appears in the ribbon. Hover any button: the tooltip says what it does and how.
  3. Open a project with MEP work in it and a plan view (Emperor never changes anything until you press a button).
  4. Try one tool from the list below. Every change is one undo step - Ctrl+Z puts everything back.
  5. Keep this guide - it is always one click away: Emperor > Help > Instructions.

Good first tools to try

Room & Space ManagerSee every room and space (also in links) in one table; create spaces from rooms, rename, set heights.
Smart TagTag ducts, pipes, terminals and dampers in a view without overlaps - and teach it where you like your tags.
System BoxPick an element of a system and get a 3D view of only that system.
Link ManagerAll Revit links and instances in one table: reload, pin, room bounding, paths.
Emperor ExporterExport sheets to PDF / DWG with your own naming, in one go.
Claude ConnectorLet Claude (AI) read your model and do work in it, with your permission.
Something is not clear, or a tool does not do what you expect? Send a message - see Contact & feedback. Ideas for new tools are welcome.

Install

Requirements: Revit 2024 or 2025 (Emperor Exporter works from Revit 2022), pyRevit with the default IronPython engine. For the Claude Connector: Claude Desktop - no Python install needed (Emperor brings its own).

  1. Close Revit.
  2. Extract the ZIP into your pyRevit extensions folder (the folder listed in pyRevit > Settings > Custom Extension Directories, or add a new one there), so you get <extensions folder>\Emperor.extension\Emperor.tab\...
  3. Start Revit (or pyRevit > Reload). The Emperor tab appears with all panels.
  4. Claude Connector: at the first start Emperor adds itself to Claude Desktop and restarts Claude Desktop automatically (an answer Claude is writing at that moment is interrupted).
Settings, profiles and logs are stored in %APPDATA%, so they are kept when you update Emperor.

Working with the windows

  • Red buttons do the main action of a window (Import, Continue, Apply, Pin...). White buttons with red text are secondary actions.
  • Buttons react to the mouse: a soft light follows the pointer over the button, the button tints on hover and presses in when clicked. A greyed button is not available yet (for example nothing is selected).
  • Rows in tables and lists light up under the mouse; the selected row is pink with a red edge.
  • Check boxes and radio buttons turn red when on. Text boxes get a red border when you type in them. Drop-down lists, right-click menus and expandable sections react to the mouse too.
  • Messages and questions open in a small Emperor window. Copy copies the text - handy for sending an error.
  • Every Revit change made by an Emperor tool is one undo step (Ctrl+Z).

Grille Align HVAC

Spaces air terminals evenly between two references - walls, columns, beams - in the host model or in a linked model.

  1. Open a plan view. Select the grilles / diffusers first, or press the button and pick them, then click Finish.
  2. Pick the first reference element at the start of the row (click the element body, not a face).
  3. Pick the second reference at the other end.
  4. The grilles are placed with equal spacing between the two near faces.
If you get "no positive span", pick the references in the other order or pick elements whose faces are perpendicular to the row.

Horizontal Align HVAC

Puts diffuser centres on one horizontal line (a row).

  1. Select the diffusers to move (or pick them after pressing the button, then Finish).
  2. Pick ONE main diffuser. The others move up / down onto its centre line; their along-row position does not change.

Vertical Align HVAC

Same as Horizontal Align, for a column: the diffusers move left / right onto the main diffuser's vertical centre line.

Diffuser Array HVAC

Copies one diffuser, or alternates supply (SD) and return (RD) diffusers, at a fixed centre-to-centre spacing.

  1. Open a floor / ceiling plan. Optional: preselect 1 diffuser (single pattern) or 2 diffusers (SD / RD pattern).
  2. Press Diffuser Array. In the window choose:
    • Array pattern: 1 diffuser (D - X - D ...) or 2 diffusers (SD - X - RD - X - SD ...).
    • Number of additional copies (1 - 200) and X = spacing in mm (1 - 100000).
    • Direction: Horizontal right / left, Vertical up / down (relative to the view).
  3. Press Continue. If nothing was preselected you pick the diffuser (or SD, then RD).
With a preselected pair, the first one along the chosen direction is SD and the second is RD. RD is moved to exactly X from SD. Copies keep the pin state of their source. Linked diffusers cannot be copied.

Smart Insulation HVAC

Adds, updates or removes duct and pipe insulation by system type, for the whole model, the active view or the selection.

  1. Tick the duct and pipe system types to insulate.
  2. For each one choose the insulation type and the thickness in mm:
    • one value for every size, e.g. 25
    • or by size: 50:25, 150:40, 50 = up to 50 mm → 25, up to 150 mm → 40, bigger → 50 (size = diameter, or the larger side of a rectangular duct)
  3. Apply to: whole model, elements in the active view, or selected elements. Mode: add missing + update existing, add missing only, or remove. Include: fittings (on by default), accessories, flex.
  4. Preview shows what would change without changing anything. Apply does it in one undo step.
Your choices are remembered per project. Only insulation types already loaded in the project are listed.

Smart Tag HVAC

Tags ducts, flex ducts, pipes, flex pipes, air terminals, mechanical equipment, accessories and plumbing fixtures in the active view.

  1. Open a plan, section or elevation (not a 3D view).
  2. Tick the categories and choose the tag type for each, and the orientation (Auto = along the duct / pipe).
  3. Options: skip ducts / pipes shorter than X mm, gap from the element edge in paper mm, skip elements that already have a tag, skip ducts with 0 L/s flow, avoid overlapping tags, leader.
  4. Tag places the tags (one undo step) and reports how many were placed or skipped.
  • Duct and pipe tags sit beside the element (the tag's edge is the gap away from the duct's edge), not on it. Air terminal tags go in front of the terminal (the side it faces). Damper / duct accessory tags go below or above the damper, and may sit inside the duct body or a duct fitting, like hand-placed V.D tags.
  • Always horizontal keeps every tag horizontal, also on vertical runs. With Leader, the tag sits a little to the side and the leader leaves the left or right side of the text, then goes to the element.
  • Skip ducts with 0 L/s flow also skips ducts whose flow is not calculated or is below 0.5 L/s (they would show 0 on the tag).
  • Avoid overlapping tags tries five spots along the element on both sides, avoiding other tags, text notes and room / space tags and the model drawn in the view: ducts and pipes (their real width and direction), fittings, accessories, air terminals and equipment. An air terminal tag goes in front of the terminal; if a duct is there, below it, then above, behind last. A tag that finds no free spot is left out and counted in the report, unless you tick Place even without a free spot.
  • Remove tags deletes every tag of the ticked categories in the view (asks first).
  • Only categories with a tag family loaded in the project can be ticked.

Teach Smart Tag where you want the tags

  1. Run Tag on a view. Smart Tag remembers every tag it placed.
  2. Close the window and move the tags you do not like to where you want them (drag them, add or remove a leader, rotate). You do not need to fix all of them - 10 to 20 good examples are enough.
  3. Open Smart Tag again and press Learn from my changes. A moved tag is a strong vote for its new spot, a tag you left alone is a small vote that its spot was fine. You can also let it learn from tags you placed by hand in that view.
  4. From now on, with Use the spots learned from me ticked, Smart Tag tries your spots first (still avoiding overlaps), then its own.
  • Spots are learned per situation: ducts / pipes running left-right or up-down, dampers in a vertical or horizontal duct (measured from the handle side), air terminals by the side they face, and so on. Distances are in paper mm, so they work at any view scale.
  • What was learned is kept on your PC for all projects. Learned... shows it and can forget it to start again.

View Manager VIEWS New

Creates or renames plan views for many levels in one go, named from the level, and gives views a view template.

  1. Press View Manager. On the left tick the levels (All / None tick or clear the whole list).
  2. Under View types tick one or more: Floor Plan, Ceiling Plan, Structural Plan. On each row choose the view type the new views use and, if you want, the template for the new views.
  3. Under View name write a prefix and / or a suffix, and the separator that goes between them and the level name (default -; type - with spaces if you like). The view name is prefix + separator + level name + separator + suffix; the separator is only used on a side that has a prefix / suffix. The example line shows the result while you type.
  4. Press Preview to see what would happen (nothing changes), then Create.

Levels that already have a view of that type

  • Tick one of the three boxes (ticking one clears the others):
  • Skip (default) - those levels are left as they are.
  • Rename the existing view - the view of that level gets the new name. When a level has several views of that type nothing is renamed and the result says why (it is not clear which one).
  • Create a new view - one more view is made on that level, next to the views it already has.
  • A level that already has a view with exactly the new name is always left as it is, and a name already used by another view of the same type is never used twice.

Template for views

  • Press Template for views... (bottom left). Every plan, section, elevation, detail, 3D and drafting view is listed with its current template in brackets.
  • Views you selected in the Project Browser before pressing the button are already ticked. Type in the box to shorten the list (part of the view name, the view type or the template name); All shown ticks what is listed.
  • Choose the view template (or no template to remove it) and press Apply. Views the template does not fit (another view type) are left as they are and listed in the result.
  • Each run is one undo step. Dependent views are not counted as "the view of the level".
  • Your choices (prefix, separator, suffix, what to do with existing views, view types, templates, unticked levels) are remembered per project in %APPDATA%\Emperor\view_manager.json.

System Box VIEWS

Opens a 3D view with a section box around a whole duct or pipe system.

  1. Select any element of the system - duct, pipe, fitting, accessory, air terminal or equipment - or press the button and pick one.
  2. The 3D view System Box - <system name> opens, boxed around every element of the system (with 0.3 m margin).
  • If the element belongs to several systems (e.g. an AHU), you choose which ones to include.
  • It asks whether to show the walls and the other architectural / structural elements (floors, ceilings, columns, framing, doors...). No = ducts, pipes and equipment only (also for elements in linked models).
  • Running it again on the same system refreshes that view. Shift + click the button to always create a new view.
  • Other systems are hidden with view filters, one per system type, rule System Type equals <type> (categories: air terminals, duct accessories / fittings / insulations / linings / placeholders, ducts, flex ducts - and the same for pipes). A filter that already has that rule is reused, whatever its name, and gets Flex Ducts and Air Terminals (Flex Pipes for pipe filters) added if they are missing. Mechanical equipment stays visible.
  • Prefix: when filters have to be created, or existing system filters do not start with the prefix, System Box asks for the prefix (it suggests the prefix your model's filters already use, e.g. ABC). New filters are named <prefix>_<system type> (or just the type name when it already starts with the prefix) and the prefix is added to the names of the existing ones. Cancel = use only the filters that exist, without changes.
  • The prefix, separator and on / off switch are in %APPDATA%\Emperor\system_box.json.

Crop to 3D VIEWS

Turns a rectangle you drag in a plan view into a 3D view of only that area, for that floor.

  1. Open a floor plan or ceiling plan and press Crop to 3D.
  2. Drag a rectangle around the area.
  3. A new 3D view Crop to 3D - <plan name> opens with a section box:
    • Bottom = the bottom of the plan's view range.
    • Top = just under the floor of the level above, over the picked area. Floors in linked models count too, so it works with a linked architectural model.
    • If no floor is found over the area: the level above; with no level above: the top of the view range.
The box follows the plan's orientation, so rotated plans work too. The view's Comments say what the top was taken from.

Room & Space Manager ROOM & SPACE

One window with a ROOMS tab and a SPACES tab: the host model's and every loaded link's rooms / spaces in one table. The window is now more compact (smaller panels and fields) so more of the table fits on screen.

Table

  • Columns: tick box, Name, Number, Level, Phase, Area, Height (m), Source (Host / Link), Linked Model, Element Id, Status (Placed / Not placed / Not enclosed). Click a header to sort.
  • Tick boxes choose the rows that changes are made to: Tick shown ticks every host row the table shows, Untick all clears them. "Apply to" has a Ticked rows choice too.
  • Filters above the table: search box, Level, Source, Status.
  • Ctrl / Shift + click for several rows. Double-click a row (or Select in Revit) to select it in Revit - linked rooms and spaces too.
  • Refresh after you change rooms / spaces outside the window. Results / Log shows the report of the last operation.

Edit selected

  • Rename: select ONE row (or tick one), type the new name and number (they are filled in from the row) and press Rename.
  • Set Height: tick the rows (or select them when none is ticked), type the height in meters (measured from the base of the room / space) and press Set Height. The upper limit becomes the room's own level and the limit offset = base offset + height.
  • Linked rooms / spaces are read-only and skipped. Each change is one undo step.

Match spaces to rooms (SPACES tab)

  • Each space takes the values of the room it sits in - host or linked room, same phase: Height (on by default) and / or Name and number.
  • All Spaces does every host space. Selected Space does only the ticked space(s), or the selected one when none is ticked.

Apply to

Every operation on a tab works on: all host rows, the filtered rows the table shows, or the selected rows. Linked elements are read-only and always skipped.

Find & replace

  1. Rooms: names. Spaces: choose Target field Name or Number.
  2. Type Find text and Replace with; optional Case sensitive / Match whole word; optional prefix / suffix.
  3. Apply Changes shows a preview of the changes - confirm to apply.

Create spaces (SPACES tab)

  1. Choose the Phase.
  2. Keep Copy name and number from the room above on to take them from host or linked rooms. Spaces without a room get the default name and a running number from the start number (never repeats an existing number).
  3. Press All Levels, or Pick Levels... to tick the levels in a list. The whole run is one undo step.

Spaces from rooms (SPACES tab)

  1. Choose the Phase in Create spaces, then press Create Spaces from Rooms... and pick the levels (all are picked at first).
  2. Emperor puts one space at every room on those levels - host rooms and rooms in loaded links (a linked room goes on the host level at the same height). Rooms that already have a space are skipped.
  3. Name and number and Base offset and height are copied from the room when ticked. One undo step.
Spaces are bounded by host walls / separators and by links whose link TYPE has Room Bounding ON (you can switch it in the Link Manager). Links with it OFF are listed before creation.

Clean up & tagging

  • Delete Unnamed: deletes spaces with an empty name (optionally also "Space" / your default name, and not placed / not enclosed spaces). Asks first.
  • Recenter for Tags: moves each space's location point to an interior point near its centre.
  • Delete Spaces on Levels...: pick levels (and / or "Not placed spaces") and delete EVERY host space on them. Asks first; Revit Undo brings them back.

Link Manager LINKS

Every Revit link and every instance of it in one table, with all link actions in one place.

Table

  • One row per link: status, reference type, Room Bounding, path type, workset, shared site, pin state, instance count, path. Links not loaded / not found are red.
  • Click a row to expand its instances (shared position and site, X/Y/Z, rotation, worksets, level, Pin / Unpin button per instance).
  • Filters: search, shared site, "Not fully pinned", "Not loaded / not found", Clear filters. Select all shown ticks only what is shown.

Actions

  • Pin / Unpin selected or all. Reload all / selected. Unload, Remove (with confirmation), Make Overlay / Attachment, Room bounding ON / OFF.
  • Room Bounding: tick the check box in a link's row - it applies at once.
  • Select in Revit: selects and zooms to the ticked instances.
  • Export CSV: the shown links, one line per instance.
  • Link files...: link many .rvt files at once - relative / absolute, overlay / attachment, origin or shared coordinates, worksets, pin after, Room Bounding ON.
  • Copy to model...: pick other open models, check the preview, then Copy. Paths, worksets, pin state, exact position and shared site are copied; the "Select the Position" dialog is answered automatically with the source site. Targets stay open and unsaved; one undo step per target.
Safe by design: the tool never publishes or acquires coordinates and never saves linked files. If Revit asks to save shared positions to a link, answer "Do not save". For a non-English Revit, put the translated dialog texts in lib\linkmgr_settings.json.

Excel to Drafting IMPORT

Draws an Excel print area in a Revit drafting view: fill colours, fonts, alignment, borders, merged cells and images.

  1. In Excel: Page Layout > Print Area > Set Print Area on the sheet you want, keep that sheet active and save (.xlsx). No print area = the used range.
  2. Press Excel to Drafting, then Add files... (one or more .xlsx).
  3. Mode:
    • Create new drafting view(s) - one view per file. Empty view name = file name; with several files the name is a prefix.
    • Update an existing drafting view - one file only; pick the target view. What the tool drew before in that view is cleared and drawn again.
  4. Press Import. The summary lists which file went into which view and any problem.
The view is set to 1:1 while drawing (needed for correct text and cell sizes) - you can change the scale afterwards. Update mode removes every filled region, text note and image in the target view, so use a view dedicated to the import. Types created are named XL_...; purge unused ones when you like.

Emperor Exporter EXPORT

Batch export of sheets and views to PDF, DWG, DXF, DGN, DWF, DWFx, NWC, IFC and images.

  1. Selection tab: Sheets or Views. Ctrl / Shift + click rows, Space or Check Selected to tick them. Search, view-type filter, extra columns, your saved sets and Revit sheet sets. Set the file name rule, e.g. {SheetNumber}_{SheetName}_{Revision} - or press Build... (see Name builder below).
  2. Formats tab: tick the formats. Every option your Revit version offers is shown with a short explanation next to it (also as a tooltip); Reset to defaults per format. PDF can be combined into one file; DWG / DXF can use an export setup and xrefs.
  3. Create tab: choose the export folder (Browse), what to do if a file exists, then Export. Cancel and Retry Failed are available; a CSV report is written.

Folders

  • One folder per format. The folder name has its own Build... table. The default gives 01. PDF, 02. DWG ...: FormatNo (the number of the format among the ticked ones, Digits 2 = 01, suffix ". ") followed by Format. Change prefix, suffix, digits or start to get 1_PDF, PDF (1), A01 - PDF ...
  • Date folder (optional): every export goes into its own folder with the date, or the date and time.
  • Sub-folder rule: folders per sheet from its parameters, e.g. {Revision} or {Sheet Group}\{Revision} (Build... lists the parameters). Order puts the format folder first or the sub-folder first.
  • The line under the settings shows an example of where a file will go.

Name builder (file name, sub-folder, format folder)

  • Build... opens a table with one row per part, left to right. Add Field = a sheet / view / Project Information parameter; Add Count = a running number; Add Text = fixed text; the quick buttons add separators (_ - ., and \ for a sub-folder).
  • Every field has a Prefix and a Suffix that are written only when the field has a value - e.g. Revision with prefix _Rev. gives _Rev.P02, and nothing at all for a sheet without a revision.
  • Digits pads numbers (2 = 01, 3 = 001). A Count has Start and Step (start 10, step 10 = 10, 20, 30...) and counts in the order of the queue, per format.
  • Arrows move a row up or down, the cross removes it. The preview shows the first three results.

DWG: Bind images as OLE New

Revit exports every picture on a sheet (title block logos, photos) as a separate image file that the DWG only links to - so you have to send the image files with every DWG. With Formats > DWG > Images > Bind images as OLE ticked, the pictures are put inside the DWG and the image files are deleted: one file per sheet, nothing in the External References palette.

  • Works by itself after each DWG export - AutoCAD is not needed. Revit 2025 and newer (the box is greyed out in older versions).
  • The picture becomes an OLE object in the layout, at the same place and size, on the layer of the original image.
  • The DWG gets bigger, because the pictures are now in it. Pictures wider than 1600 px or higher than 1200 px are scaled down, because AutoCAD shows bigger OLE pictures blank.
  • Pictures that are rotated, clipped to a polygon, or inside a rotated / mirrored block stay linked; they are listed in the notes of the export report and their image files are kept.
  • If something goes wrong with a file, it is left exactly as Revit exported it and the reason is in the notes.
  • With "views as external references" ticked, the xref files of the sheet are handled too.
  • This option is new: open the first DWGs of a project in AutoCAD and check the layout before sending them.

Black lines in PDF New

  • Ticked (default): PDFs print every duct, pipe, fitting, accessory, insulation, terminal and piece of equipment with black lines. Emperor uses the filter Emperor Export (created in the model the first time if it does not exist) and switches an existing PRINT filter on. Other filters that colour lines are drawn black too, so the order of the filters does not matter.
  • Drafting views and legends on the sheet (general notes, legends, details) print their lines and legend symbols black too - also line styles that were given a colour in the view - and coloured text and dimensions print black. Pictures (logos) and coloured fills keep their colours.
  • DWG, DXF, DGN, DWF and images: PRINT and Emperor Export are switched off, so the system colours and layers stay as designed.
  • Only the views on the exported sheets are affected (through their view template when the template controls the filters), and every change is undone after each file - your views and templates stay exactly as they were.
Profiles (top bar) save every setting; the last used settings come back automatically. Schedules cannot go to DWG / DXF / DGN / images - those rows are marked Skipped.

Claude Connector CLAUDE

Lets Claude Desktop (or Claude Code) work with the Revit project you have open. It starts by itself with Revit.

  1. Nothing to install. The first time, Emperor downloads its own small Python (the official embeddable build from python.org, about 11 MB) into a private folder. It is not installed on Windows, does not touch PATH and is invisible to other programs. Emperor only uses it when python.exe is signed by the Python Software Foundation. If that download is not possible (offline, blocked), a Python already installed on Windows is used instead.
  2. At Revit start the connector starts its listener (ports 48890-48899) and, when Connect Claude automatically whenever Revit starts is ticked (Claude Connector window), adds itself to Claude Desktop. If Claude Desktop is open, Emperor closes it and opens it again by itself so it loads the connector - nothing to do. With the box unticked, press Reconnect + restart Claude Desktop once instead.
  3. Claude Desktop starts the connector with Emperor's own Python: "command": "<private folder>\python.exe", "args": ["<extensions folder>\Emperor.extension\mcp_server\emperor_mcp_server.py"]. An entry that points to another folder or another Python (for example the older py -3 entry) is updated automatically - Claude Desktop restarts once for that.
  4. Open Claude Connector to see the status lights. In Claude Desktop ask: "Check the Revit connection".

Emperor Revit Skills (Claude Code)

  • If Claude Code is installed, press Set up Claude Code (skill) in the Claude Connector window (it also happens at Revit start when automatic connection is on). Emperor installs the skill emperor-revit-skills and registers the connector for Claude Code.
  • The skill is Claude's playbook for Revit work: start with the session brief, ask small questions of the model, use the one-call HVAC tools and saved scripts, dry-run big changes. It is only read when a Revit task starts, so it costs almost nothing in other chats.
  • Learn Standards: the first time Claude works on a company's model it reads that model's naming once - filter prefix and separator, system names and abbreviations, sheet-number pattern, view / template naming, duct / pipe / tag types in use - and keeps it as a company profile on your PC only (%APPDATA%\Emperor\standards), keyed by the organisation in Project Information. Every new project of that company adds to it. Tell Claude a rule ("filters start with ABC_") and it is saved there too. These rules are never shipped with Emperor or the skill.

Icon in Claude Desktop

  • Claude Desktop shows the connector as Emperor-Revit with a letter icon: connectors that run on your PC cannot have their own icon in the current Claude Desktop. Emperor already contains a Claude Desktop extension with the Emperor icon (folder claude_desktop) for when Claude Desktop allows installing extensions from a file again.

First time on a new PC

  1. Install Claude Desktop and sign in. Install Emperor (see Install). No Python is needed.
  2. Make sure the PC is online and start Revit. Emperor downloads its own Python in the background (a few seconds) and connects Claude Desktop, which restarts once.
  3. Open Claude Connector: all status lights should be green, including "Emperor's own Python is ready".
  4. In Claude Desktop, Settings > Developer lists Emperor-Revit as running. Ask Claude: "Check the Revit connection".
PC without internet? Download python-3.12.10-embed-amd64.zip from python.org on another PC and put it, as it is, in a folder named python inside Emperor.extension. Emperor unpacks and uses it instead of downloading.

Saving tokens and time

  • Project Memory: Claude keeps one small file per project with the model facts (levels, links, duct / pipe types and systems, insulation and terminal types, plan views) and your standards and notes. Tell Claude a rule once ("supply ducts are Rectangular - Taps", "ceiling height 2.9 m") and it is remembered in every new chat. Open Project Memory in the Claude Connector window shows the files.
  • Tools given to Claude: All tools, Modeling (no scripts) or Read-only. Every tool description is sent with every message, so a smaller set costs fewer tokens (read-only is about 60 % smaller). Claude Desktop restarts to load the change.
  • PDF drawings as vectors: Claude reads the lines and text of a PDF on your PC instead of looking at pictures, so it is cheaper and more exact. pdf_to_ducts and cad_to_ducts turn duct double-lines into centerlines with their width, join tees and elbows and create the ducts in one call, after a preview.
  • New one-call tools: summaries (counts / lengths grouped by type, system, level), model check (open ends, ducts without a system, terminals without flow), duct sizing by velocity (preview first), Smart Tag and Smart Insulation.
  • Answers come back as compact tables, pictures are smaller by default, and long scripts stop by themselves after 15 minutes (or the time you set).
  • Reconnect + restart Claude Desktop writes the connector entry again and restarts Claude Desktop. Copy config copies the MCP settings for other clients (Claude Code).
  • Revit must be idle (no open dialog or running command) to answer Claude.
  • Your own saved scripts: %APPDATA%\Emperor\scripts. Project notes for Claude: %APPDATA%\Emperor\project_notes.md.

Shortcut Guard TOGGLES

Revit shortcuts work by the letter a key types, so with an Arabic (or any non-English) keyboard they do nothing. Shortcut Guard keeps Revit in English for you.

  1. Click Shortcut Guard once to turn it ON - the icon turns red with a tick. Click again to turn it OFF - the icon turns grey.
  2. While it is ON and Revit is in front, the keyboard switches to English by itself, so shortcuts (WA, DT, VV...) always work.
  3. While you type text - a text box, a text note, a room name, a parameter value, anything with a text cursor - your language is left alone, so you can type Arabic there.
  4. When you go to another program, the language you had before comes back.
ON / OFF is saved and applied by itself every time Revit opens - no need to click again. It checks the front window four times a second and uses almost no CPU.
Without Emperor, Windows can do part of this: Settings > Time & language > Typing > Advanced keyboard settings > Let me use a different input method for each app window.

Sync Views TOGGLES

Plans open on the same spot: switch from one plan to another and the new plan keeps the same zoom and position.

  1. Click Sync Views once to turn it ON - the icon turns red with a tick. Click again to turn it OFF - the icon turns grey.
  2. Zoom into an area of a plan, then open (or switch to) another plan: it shows the same area.
  • Works between floor plans, ceiling plans, structural plans and area plans of the same project only. 3D views, sections, elevations, drafting views and sheets are never changed.
  • Going plan > section > plan: the second plan still opens on the spot of the first plan.
  • ON / OFF is saved and applied by itself every time Revit opens.

Troubleshooting

ProblemFix
A panel appears twiceEmperor is installed twice (two copies of Emperor.extension in your extensions folders) - keep one and reload pyRevit.
Claude Desktop does not see RevitOpen Claude Connector > Reconnect + restart Claude Desktop. The Python status light should be green ("Emperor's own Python is ready"). If not, check the internet connection once and restart Revit. What happened is written in %APPDATA%\Emperor\claude_connector_register.log.
Room & Space table is empty after changesPress Refresh.
Claude Desktop shows Emperor-Revit as failedOpen Claude Connector > Reconnect + restart Claude Desktop. If Emperor's own Python was deleted, it is downloaded again (the PC must be online once).
Toggle icon does not match (red / grey)Click the toggle once - one click always flips what is really running, and the icon follows.
New spaces are not bounded by the linked wallsTurn Room Bounding ON for that link (Link Manager) and create again.
A window opens with plain grey controlsThe Emperor theme could not load - the tool still works. Send the log file named above.
Any error messageCopy the full text (and the log file) and send it - every tool writes the details.
